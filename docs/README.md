## Current Projects

TheSuperEevee currently includes:

- **OploJDecom** — A fast, lightweight Java decompiler powered by Vineflower
- **OploJDiff** — A Java JAR comparison tool with source, API, and dependency analysis
- **TowelWrap** — A customizable two-player strategy game
- **OploLabs Website** — The official website for OploLabs
- **ACS Web Apps** — A collection of ad-less web projects
- **Immortality MC Mod** — A Minecraft modification developed in Java
