# Getting Started

Welcome to TheSuperEevee's website. This guide will help you explore the platform and understand what's available.

## Who is TheSuperEevee?

TheSuperEevee is a central developer platform for showcasing, discovering, and accessing software and development projects.

It combines:

- A project portfolio
- A software catalog
- A code repository
- Technical documentation
- Development updates

## Exploring the Platform

### Homepage

The [homepage](../) introduces TheSuperEevee and provides quick access to:

- Featured projects
- Development areas
- Latest updates
- GitHub activity

### Projects

The [Projects page](../projects/) catalogs development projects with:

- Search and filtering by category and status
- Project descriptions and technologies
- Links to source code, websites, and documentation

Each project has its own detail page with an overview, features, technologies, and external links.

### Software

The [Software page](../software/) focuses on finished or actively maintained applications and tools, including:

- Name and description
- Version information
- Platform compatibility
- Download and documentation links

### Code

The [Code page](../code/) showcases programming-related work such as:

- Libraries and utilities
- Code examples
- Open-source experiments

### Documentation

You're reading the documentation now. It provides:

- Getting started guides
- Developer setup instructions
- Tool and API references

### Updates

The [updates feed](../) provides a timeline of development activity including:

- New releases
- Project announcements
- Feature additions
- Bug fixes
- Development milestones

## Browsing Projects

Projects are organized by:

- **Category** — Developer Tool, Game, Web Application, Minecraft Mod, Website
- **Status** — Active, In Development, Archived, Experimental

Use the search box and filters on the [Projects page](../projects/) to find specific projects.

## Following Development

To stay updated:

1. Visit the [GitHub repository](https://github.com/Thesupereevee1)
2. Check the [Updates section](../) for recent development activity
3. Explore new projects as they are added

## Running Locally

The website is a static site hosted on GitHub Pages. To run it locally:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000/](http://localhost:8000/).

See the [Developer Setup](developers/setup.md) guide for more details.
